# 채보 구간 전환과 재시작: 4단계

RoomSession의 기존 Chart/Rooms/Combat은 첫 구간입니다. Sections 배열이 비어 있으면 기존 단일 채보 흐름을 사용합니다. 추가 구간은 같은 음악을 계속 재생하면서 각자의 채보와 방·대상 연결을 사용합니다. 씬이나 프리팹 오브젝트를 실행 중 새로 만들지 않습니다.

## 구간 제작

1. 구간별 RoomChart를 만들고 같은 음악·BPM·음악 시작 지연·반복 여부·입력 보정값을 사용합니다.
2. 모든 채보 시각은 곡 전체 기준입니다. 예를 들어 40초에 시작하는 구간의 첫 입력이 42초라면 2초가 아니라 42초에 작성합니다.
3. RoomSession의 Sections 항목에 고유 id, Chart, Rooms, Combat을 연결합니다. `initial`은 첫 구간 예약 ID입니다. 같은 채보를 여러 항목에 연결하지 않습니다.
4. 각 구간에 독립된 RoomBinding과 RoomCombat 연결을 사용합니다. 다음 구간의 시작 방은 이전 구간 마지막 방과 같은 위치에 배치하되 오브젝트는 따로 둡니다. 기존 방을 복제해 기본 템플릿을 마련한 뒤 에디터에서 해당 채보를 편집·적용할 수 있습니다.
5. 방 아래에 RoomSession, 플레이어, RoomCombat을 두지 않습니다. 비활성 구간의 방은 꺼지므로 공통 컨트롤러와 카메라는 별도 계층에 둡니다.

맵 에디터의 가져오기와 씬 적용은 Sections에 등록된 채보도 찾습니다. 추가 구간 적용 시 그 구간의 방과 적 연결만 갱신하며 첫 구간 채보·플레이어 시작 위치·카메라 시작 위치를 덮어쓰지 않습니다. 구간별 보스 전용 표적과 경로 기준점은 재생성되는 방/적 외부에 배치합니다. 서로 방 계층이나 Combat을 공유하면 씬 적용을 거부합니다.

## 전용 진행 코드

StageDirector에서 `QueueSection("boss")`를 호출합니다. 현재 채보가 완료된 뒤에만 예약할 수 있으며 실제 교체는 입력 묶음, 판정 결과, 기본 표시와 Tick 처리가 끝난 시점에 실행합니다. 콜백 도중 판정 모델을 교체하지 않습니다.

예를 들어 OnChartCompleted에서 다음 구간을 바로 예약하거나, Tick에서 등장 연출이 끝난 곡 시점까지 기다렸다가 예약할 수 있습니다. 예약 성공 여부를 확인하고 실패를 매 프레임 무한 재시도하지 마세요. 전환 완료 후 `OnSectionStarted(id)`가 호출됩니다. 첫 구간 시작은 기존 BeginStage를 사용합니다.

- 현재 채보가 끝나지 않았거나 다른 예약이 있으면 false입니다.
- 다음 구간의 첫 판정 허용 구간이 이미 열렸으면 거부합니다. 충분히 앞서 전환해 예고 시간을 확보하세요.
- 음악 설정이 다르거나 다음 시작 방이 현재 채보의 도착 위치와 다르면 거부합니다.
- 마지막 구간 뒤에만 CompleteStage를 호출합니다. 예약 중에는 클리어할 수 없습니다.
- 구간마다 OnChartCompleted가 한 번 호출됩니다. 정확도는 모든 구간의 정확 판정 수/전체 판정 수로 계산합니다.
- 음악과 입력 시계는 전환 시 다시 시작하지 않습니다. 전환 이전 입력은 다음 판정에 소급 적용하지 않습니다.

등록된 구간을 자동 순서대로 재생하는 기능은 아닙니다. 스테이지별 코드가 전환 시점을 결정합니다. 런타임 전환 구성에 오류가 발생하면 잘못된 클리어로 처리하지 않고 로그를 남긴 뒤 첫 구간으로 재시작합니다.

## 재시작 상태

RoomSession은 처음 구간의 연결을 보관합니다. 사망 후 재시작하면 음악·채보·누적 점수·전환 예약을 초기화하고 첫 구간으로 돌아갑니다. 비활성 구간의 방과 표적은 숨겨집니다.

보스/소품용으로 StageResetState 컴포넌트를 씬에 배치하고 Roots에 복원할 계층을 지정한 다음 RoomSession의 Reset State에 연결합니다. 세션 시작 시 한 번 캡처하며, 재시작 때 부모·로컬 위치·회전·크기·activeSelf·Renderer.enabled·SpriteRenderer.color를 복원합니다. 공통 세션이나 카메라, 플레이어를 포함하는 씬 전체 루트 대신 보스·소품 계층만 지정하세요. 저장할 상태는 세션 Start 전에 준비되어 있어야 합니다.

복원은 오브젝트 삭제를 되돌리지 않습니다. 보스나 파괴 가능한 소품은 Destroy 대신 외형을 숨겨 보존합니다. Animator 상태, 물리 속도, 파티클, 다른 스크립트의 내부 변수와 코루틴은 각 보스의 ResetStage에서 명시적으로 초기화해야 합니다. StageDirector 자신의 코루틴은 재시작 시 중단됩니다. 표적 경로는 ResetStage 뒤에 다시 초기화합니다.

현재 재시작은 곡 처음부터입니다. 임의 시점 탐색, 구간 체크포인트 시작, 이동 중 구간 교체, 빈 채보 구간은 아직 지원하지 않습니다. 입력 없는 등장 연출은 이전 채보 완료 뒤 Tick에서 진행하고 다음 구간을 예약하면 됩니다.

## Unity 확인 항목

기존 단일 채보 시작/클리어, 추가 구간으로 전환할 때 음악 연속성, 같은 위치에서의 방 교체, 전환 경계의 입력, 다음 구간에서 사망 후 첫 구간 복원, 마지막 클리어 기록의 누적 정확도, 구간별 맵 저장/재적용을 확인합니다. 자동 검사에서는 판정 시각·늦은 진입 거부·이전 입력 차단과 컴파일을 확인하며 Unity는 실행하지 않습니다.
