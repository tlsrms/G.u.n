# 방 크기와 이동 설정: 2단계

기존 에디터의 방 속성에 설정을 추가했습니다. 기존 씬과 채보 파일은 자동으로 덮어쓰지 않습니다. 새 설정을 저장한 뒤 기존의 씬 적용 기능을 사용하세요.

## 사용 방법

1. 방을 선택하고 `가로`, `세로`를 월드 단위로 설정합니다. 0이면 곡 설정의 기본 방 크기를 사용합니다.
2. 크기를 바꾸면 인접 방과의 거리가 달라질 수 있습니다. `시간순 이전 방에 붙이기`에서 방향을 선택하면 두 방의 경계가 정확히 맞도록 위치 보정값이 계산됩니다. 뒤쪽 방들도 필요하면 차례로 다시 붙이세요. 기존 `이 방 옆에 방 추가`는 현재 방 크기에 맞춰 새 방을 배치합니다.
3. 해당 방으로 들어오는 `이동 시간/초`를 설정합니다. 0이면 기존 RoomChart.moveDuration을 사용합니다. 정확 입력 박자는 그대로이며, 이동 완료 시각만 변경됩니다.
4. 속도 곡선을 선택합니다. Smooth는 기존 완만한 출발·도착, Linear는 일정 속도, EaseIn은 가속, EaseOut은 감속입니다. 네 종류의 곡선을 제공하며 임의 AnimationCurve 편집은 아직 지원하지 않습니다.
5. 곡 설정의 `방 판정선 시작 크기`는 가장 긴 방의 변보다 크게 설정합니다. 예를 들어 6×18 방이라면 18보다 커야 합니다.

가로 6·세로 18, 이동 시간 0.8초·EaseIn인 방을 위쪽에 붙이면 긴 세로 방으로 가속하며 이동합니다. 이후 방은 자신의 크기·이동 시간을 별도로 지정할 수 있습니다.

`격자 기준 X/Y 보정`은 격자 좌표에 더하는 월드 단위 위치입니다. 방 드래그는 기본 격자로 다시 맞추므로 보정값이 0이 됩니다. 세밀한 배치는 보정값 또는 붙이기 버튼을 사용하세요. 기본 방 크기는 격자 간격도 결정하므로 이미 배치한 맵에서 변경하면 전체 배치에 영향을 줍니다.

## 저장과 실행

- 방별 크기·위치 보정·이동 시간·곡선은 초안/적용 맵에 저장되고 타임라인 복제에도 유지됩니다.
- 씬 가져오기는 RoomBinding의 실제 크기와 위치, 이동 노트의 개별 설정을 가져옵니다.
- 에디터의 이상적인 정박 이동과 런타임 이동은 동일한 곡선 계산을 사용합니다. 실제 플레이에서는 성공한 입력 시각에 이동이 시작되므로 조기/늦은 입력만큼 차이가 날 수 있습니다.
- 벽·문·판정선·방 선택 영역·사망 연출은 직사각형 크기를 사용합니다. 판정선 색상과 판정 허용 범위는 유지합니다.
- 긴 이동 때문에 다음 입력을 처리할 수 없는 채보, 잘못 연결된 방, 음수/비정상 크기와 이동 설정은 검증에서 거부합니다. 이전 방과 일부만 겹치는 방도 이전 사용이 끝날 때까지 표시를 미룹니다.

현재 연결은 수평/수직 중심축을 맞춘 직사각형 방 사이의 직선 이동입니다. 한쪽으로 치우친 출입구, 방 내부의 여러 경유점, 이동 중 방향 전환은 후속 작업입니다. 방 크기 편집만으로 기존 경로 전체를 자동 재배치하지 않습니다.

Unity 확인 항목: 기존 채보 재생, 서로 다른 크기의 방과 문 경계, 정박 미리보기와 실제 이동, 복제·저장·씬 적용 후 다시 가져오기, 직사각형 방에서 사망과 재시작. 자동 검사는 순수 데이터/판정과 컴파일까지 수행하며 Unity는 실행하지 않습니다.
