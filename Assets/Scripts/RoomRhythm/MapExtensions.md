# 방 크기와 이동 설정: 2단계

기존 에디터의 방 속성에 설정을 추가했습니다. 기존 씬과 채보 파일은 자동으로 덮어쓰지 않습니다. 새 설정을 저장한 뒤 기존의 씬 적용 기능을 사용하세요.

## 사용 방법

1. 방을 선택하고 `가로`, `세로`를 월드 단위로 설정합니다. 0이면 곡 설정의 기본 방 크기를 사용합니다.
2. 크기를 바꾸면 해당 방을 시간순 이전 방의 면에 자동으로 다시 붙입니다. 드래그 또는 `시간순 이전 방에 붙이기`의 방향 버튼으로 붙일 면과 위치를 바꿀 수 있습니다. 긴 면의 위치는 기본 방 크기(기본값 6) 간격으로 맞춥니다. 뒤쪽의 선택되지 않은 방들도 필요하면 차례로 다시 붙이세요. `이 방 옆에 방 추가`도 같은 면 맞춤 계산을 사용합니다.
3. 해당 방으로 들어오는 `이동 시간 (박, 0: 기본값)`을 설정합니다. 직사각형은 기본 방 크기(기본값 6)의 칸으로 보고, 다음 방과 맞닿은 칸의 중심까지 이동합니다. 예를 들어 가로 18 방의 오른쪽 끝 아래에 다음 방이 있으면 가로방의 오른쪽 끝 칸 중심에 도착합니다. 시간은 이전 방의 대기 위치에서 공유 통로를 지나 이 도착점까지의 전체 이동에 적용됩니다. 0이면 기존 RoomChart.moveDuration을 사용합니다. 직접 지정한 이동 박 수는 맵 에디터에서 BPM을 바꿔도 유지됩니다. 기존 초 단위 저장값은 현재 BPM에 맞는 박 수로 표시하므로 기존 이동 시간은 그대로입니다. 정확 입력 박자는 그대로이며, 이동 완료 시각만 변경됩니다. 다음 방이 없는 마지막 방은 기존처럼 방 중심에 도착합니다.
4. 속도 곡선을 선택합니다. Smooth는 기존 완만한 출발·도착, Linear는 일정 속도, EaseIn은 가속, EaseOut은 감속입니다. 네 종류의 곡선을 제공하며 임의 AnimationCurve 편집은 아직 지원하지 않습니다.
5. 곡 설정의 `방 판정선 시작 크기`는 유한한 양수로 설정합니다. 각 축은 시작 크기에서 해당 방의 가로·세로 크기로 변하며 정확 박에 경계에 도달합니다. 예를 들어 시작 크기 12인 6×18 방은 가로가 줄고 세로가 늘어납니다. 시작 크기와 같은 길이의 축은 크기가 유지됩니다.

가로 6·세로 18, 이동 시간 2박·EaseIn인 방을 위쪽에 붙이면 긴 세로 방으로 가속하며 이동합니다. BPM 120에서 2박은 1초입니다. 이후 방은 자신의 크기·이동 시간을 별도로 지정할 수 있습니다.

`격자 기준 X/Y 보정` 입력은 제거했습니다. 보정값은 내부 저장용으로 유지하며 면 맞춤 계산이 자동으로 설정합니다. 6×18 방의 긴 면에는 6×6 방을 세 위치에, 6×12 방에는 두 위치에 붙일 수 있습니다. 기본 방 크기는 맞춤 간격도 결정하므로 이미 배치한 맵에서 변경하면 전체 배치에 영향을 줍니다.

## 저장과 실행

- 방별 크기·위치 보정·이동 시간·곡선은 초안/적용 맵에 저장되고 타임라인 복제에도 유지됩니다.
- 씬 가져오기는 RoomBinding의 실제 크기와 위치, 이동 노트의 개별 설정을 가져옵니다.
- 에디터의 이상적인 정박 이동과 런타임 이동은 동일한 곡선 계산을 사용합니다. 실제 플레이에서는 성공한 입력 시각에 이동이 시작되므로 조기/늦은 입력만큼 차이가 날 수 있습니다.
- 벽·문·판정선·방 선택 영역·사망 연출은 직사각형 크기를 사용합니다. 판정선 색상과 판정 허용 범위는 유지합니다.
- 긴 이동 때문에 다음 입력을 처리할 수 없는 채보, 잘못 연결된 방, 음수/비정상 크기와 이동 설정은 검증에서 거부합니다. 이전 방과 일부만 겹치는 방도 이전 사용이 끝날 때까지 표시를 미룹니다.

직사각형의 면 일부만 맞닿는 연결도 허용하며, 모서리만 접하거나 서로 겹치는 배치는 연결로 인정하지 않습니다. 입력 방향은 맞닿은 면을 기준으로 정하고, 문과 통로는 공유 구간의 가운데에 배치합니다. 캐릭터는 공유 통로를 지나 다음 출구 쪽 칸 중심까지 이동하므로 치우친 연결에서도 벽을 가로지르지 않습니다. 이동 곡선은 두 구간의 총 거리에 적용하며, 미리보기·경로 화살표·실제 플레이가 같은 계산을 사용합니다. 임의의 추가 경유점 편집은 지원하지 않습니다. 방 크기 편집만으로 기존 경로 전체를 자동 재배치하지 않습니다.

Unity 확인 항목: 기존 채보 재생, 서로 다른 크기의 방과 문 경계, 정박 미리보기와 실제 이동, 복제·저장·씬 적용 후 다시 가져오기, 직사각형 방에서 사망과 재시작. 자동 검사는 순수 데이터/판정과 컴파일까지 수행하며 Unity는 실행하지 않습니다.
