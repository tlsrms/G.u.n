# 보스 장애물·투사체 연결: 3단계

기존 채보의 문과 적을 다른 외형·위치의 대상으로 연결할 수 있습니다. 판정, 정확도, 입력 순서는 RoomRun을 계속 사용합니다. 일반 적 프리팹과 기존 씬은 변경하지 않았습니다.

## 기본 연결

1. 기존 맵 에디터에서 문 또는 적 채보를 만들고 씬에 적용합니다.
2. `Assets/Prefabs/Characters/StagePropTarget.prefab`을 별도 Stage Targets 루트 아래에 배치합니다. 방과 일반 적은 에디터가 재생성하므로 그 자식에 두지 않습니다.
3. 표적의 Role을 설정합니다. `Shot`은 적 제거 판정, `Breakthrough`는 문 파괴 판정입니다.
4. Target Id에는 Shot이면 해당 EnemyNote.id, Breakthrough이면 문이 있는 MoveNote.destinationId를 입력합니다. 이름이나 순번이 아니라 RoomChart의 채보 ID입니다.
5. RoomCombat의 Stage Targets 배열에 해당 컴포넌트를 연결합니다.

같은 역할·ID의 기본 적/문이 이미 있어도 실행 중에는 숨겨지고 전용 표적이 대신 사용됩니다. Shot 표적은 기존 RoomEnemy 연결 없이도 사용할 수 있습니다. 등록되지 않은 채보는 기존 표시를 유지합니다. 중복 역할·ID, 누락된 채보, 다른 씬의 참조는 검증에서 거부합니다.

공용 프리팹의 사각형은 교체 가능한 임시 외형입니다. Prop visuals 아래에 사용할 바위 등의 외형을 편집하고, 흰 아웃라인과 판정 링은 유지합니다. 움직이는 것은 루트이고 표적 중심은 루트 원점입니다. 루트를 런타임에서 새로 생성하지 않습니다.

## 움직이는 투사체

Moving을 켜고 Path Start/End에 별도로 배치한 두 Transform을 연결합니다. 경로 기준점도 자동 재생성되는 방·적 외부에 배치해야 합니다. 프리팹 자식으로 기준점을 두면 표적과 함께 움직이므로 허용하지 않습니다.

채보 등장 시각에 출발하고 정확 판정 시각에 도착합니다. Ease로 일정 속도/가속/감속 등을 선택합니다. 경로의 두 끝점은 재시작 시 다시 읽습니다. 플레이어를 실시간 추적하거나 곡선 경로로 움직이는 보스 전용 대상은 StageActionTarget을 상속해서 구현합니다.

PositionAt(time)은 Transform을 움직이지 않고 해당 판정 시각의 위치를 반환해야 합니다. 입력 처리와 조준 후보 선택, 총알 선의 끝점은 이 위치를 사용합니다. 렌더 프레임보다 과거 시각의 입력도 처리할 수 있어야 하며 시간 누적 방식으로 이동하면 안 됩니다. 화면 표시는 동일한 함수로 위치를 평가합니다.

## 대응·성공·실패

- 기존처럼 이동을 시작하면 목적지 방의 사격 대상이 활성화됩니다. 이동 중 사격은 허용하고, 추가 이동 입력은 무시합니다. 아직 들어가지 않은 방의 표적을 미리 맞힐 수는 없습니다.
- 조준 범위 안에서 정확 박자가 가장 빠른 대상을 우선합니다. 투사체가 정확 박자에 플레이어 중심과 일치해도 요격 대상에서 제외하지 않습니다.
- 성공하면 전용 대상의 OnHit(time)을 한 번 호출합니다. 공용 프리팹은 외형을 숨깁니다. 일반 적 사망·문 파편 효과를 자동으로 붙이지 않습니다.
- 해당 대상으로 인해 실패하면 OnFailure(time)을 호출하고, StageDirector에는 기존 Failed 결과를 전달합니다. 일반 적의 총격 처형을 투사체에 적용하지 않습니다. 공용 실패 피드백은 유지하며 보스별 피격 연출은 전용 코드로 추가합니다.
- StageDirector는 기존 EnemyDefeated/DoorBroken 결과와 TargetId로 성공을 구분할 수 있습니다. OnAction/OnHit에서 동일한 효과를 두 번 실행하지 않도록 어느 쪽이 담당할지 정합니다.
- 재시작 때 StageDirector.ResetStage 뒤에 표적 경로를 초기화합니다. 전용 대상의 ResetTarget은 여러 번 호출되어도 같은 초기 상태로 돌아가야 합니다.

연결된 표적 컴포넌트와 루트는 실행 중 파괴하지 않고 보존합니다. 성공 시 자식 외형만 숨기고, 파편 등 별도 효과가 필요하면 전용 연출에서 처리합니다. 실패 후에도 Present가 고정된 판정 시각으로 호출되므로, 자체 실패 연출을 구현할 때는 내부 상태로 기본 표시와 구분하세요.

## 에디터와 현재 범위

기존 맵 에디터는 계속 채보를 편집합니다. 전용 대상은 별도 프리팹에서 연결하므로 보스별 설정창을 추가하지 않았습니다. 씬 적용은 Stage Targets 배열을 유지하고, 삭제될 방/적 아래에 표적이나 경로 기준점이 있으면 적용을 거부합니다. 채보 ID를 삭제한 경우 연결도 정리해야 합니다.

맵 에디터 미리보기는 여전히 기존 문/적 위치를 표시합니다. 전용 표적의 실제 경로와 외형은 Unity에서 확인합니다. 보스 투석·돌진 등의 콘텐츠와 실시간 추적은 후속 작업입니다. 채보 구간 교체는 [StageSections.md](StageSections.md)를 참고하세요. 공용 표적은 채보의 한 대상에 대응하며 물리 충돌로 별도 판정을 만들지 않습니다.

Unity 확인 항목: 기존 적/문 유지, 같은 ID 교체 시 중복 외형 숨김, 이동 중 요격·실패·재시작, 문 대신 장애물 파괴 후 이동, 맵 재적용 후 참조 유지. 자동 검사와 컴파일만 수행하며 Unity는 실행하지 않습니다.
