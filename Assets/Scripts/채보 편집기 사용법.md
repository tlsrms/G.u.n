# 시각적 맵 에디터 사용법

## 시작과 저장

MainScene을 열고 Play를 종료한다. `Window > Gun > 시각적 맵 에디터`에서 Room Chart를 지정하면 기존 작업을 자동으로 불러온다. 편집용 데이터가 없으면 현재 씬에서 자동으로 가져온다. 곡·기본 설정 탭에서 음악, BPM, 첫 박 시각, 분할과 판정 범위를 설정한다.

상단에는 `저장`과 `씬에 적용` 버튼이 있다. `저장`은 편집 중인 채보 에셋만 저장한다. 씬 연결이나 완성된 채보가 없어도 저장할 수 있다. `씬에 적용`은 현재 채보를 검증한 뒤 실제 씬에 방·문·적을 미리 배치하고 연결 및 씬·채보 파일 저장까지 처리한다. 실행 중 생성하지 않는다. 적용 중 연결 검사 실패 시 변경을 Undo로 되돌린다.

## 방을 기준으로 편집

맵의 방을 클릭하면 오른쪽에서 그 방의 모든 설정을 편집한다. 별도의 선택/배치 도구 탭은 없다. 같은 좌표에 여러 방문이 겹쳐 있으면 나열된 `nth/nbeat` 이름 중 원하는 것을 클릭한다. 빈 곳을 누르거나 겹친 칸을 반복 클릭해도 다른 방으로 자동 순환하지 않는다.

- **방·판정선 시작 박:** 방 등장, 이동 판정선 시작, 문 판정선 시작의 공통 시각. 여러 방에 같은 값을 넣으면 동시에 등장한다. 기존 채보는 방 등장 박을 기준으로 통일한다.
- **방 이동 정확 박:** WASD 입력 시각.
- **입구 문:** 문을 켜거나 끄고 사격 정확 박을 설정한다. 문 판정선은 방 등장과 동시에 시작한다.
- **옆에 방 추가:** ↑ → ↓ ← 중 원하는 방향 버튼을 누르고, 이동 박자를 직접 입력해 확정한다. 타임라인 커서 시각을 자동으로 사용하지 않는다.
- **방 위치 이동:** 버튼을 누른 뒤 방을 드래그해 이동한다. 내부 격자 좌표는 표시하지 않는다.
- **이 방 삭제:** 해당 방과 소속 적·연출을 삭제한다. 시작 방은 삭제할 수 없다.

Bundle 기능은 제거했다. 기존 에셋을 열면 Bundle 등장 시각을 각 방의 등장 시각으로 옮겨 보존한다. 이후 한 방의 등장 박을 바꿔도 다른 방은 바뀌지 않는다.

진행 방향은 시간순 방의 위치로 자동 계산하고 화살표로 표시한다. 같은 좌표도 이전 방이 사라진 뒤 다시 방문할 수 있다. 늦은 성공 입력과 이동 애니메이션까지 고려해 같은 위치의 방들이 동시에 나타나지 않도록 설정한다.

## 적과 카메라

선택한 방의 **이 방의 적**에서 8방향 버튼으로 적을 추가하거나 기존 적을 선택한다. 아래에서 **적·판정선 시작 박**, 사격 정확 박과 방향을 설정하고 삭제할 수 있다. 적 등장과 판정선 시작은 항상 같다. 적의 소속 방은 **사격 정확 박**으로 자동 결정한다. 방 A의 이동 정확 박 이상, 다음 방 B의 이동 정확 박 미만에 사격하면 A에 속한다. 사격 정확 박이 B의 이동 정확 박과 같으면 B에 속한다. 첫 이동 전의 사격은 시작 방에 속한다. 적·판정선 시작이 방 이동보다 빨라도 사격 시점의 방 소속을 유지한다. 방이나 적의 박자를 수정·드래그·복제하면 소속이 다시 계산되며, 저장과 씬 적용에도 같은 규칙을 사용한다.

**이 방의 카메라**에서 카메라 이동 또는 흔들림을 추가한다. 이동은 시작·지속 박, 도착 위치·크기·보간을 설정한다. 보라색 마커를 드래그해 도착 위치를 바꿀 수도 있다. 흔들림은 시작·지속 박, 강도와 빈도를 설정한다. 예전에 만든 소속 방 정보 없는 연출은 목록에서 계속 접근할 수 있다.

## 검증과 판정선

입장 후 적을 읽는 최소 대기 시간은 검사하지 않는다. 입장 전부터 보이는 적은 도착 후 바로 사격할 수 있다. 문·이동·적의 허용 판정 구간이 겹쳐도 정확 박의 진행 순서가 맞으면 허용한다. 이동은 이전 애니메이션 이후에 성공할 수 있는 입력 시간이 전혀 없는 경우에만 막는다. 같은 방의 같은 방향에 여러 적 채보를 만들 수 있다. 음원 종료 직전의 판정은 허용하며, 느림 허용 구간과 마지막 이동 애니메이션은 음원 종료 뒤에 끝나도 된다. 대기 시간과 곡 반복 옵션은 게임과 씬 적용의 음원 길이 검사에 동일하게 반영된다.

타임라인에서 **Shift 클릭**으로 항목을 선택에 추가하거나 해제한다. 여러 항목을 선택한 상태에서 선택된 구간을 드래그하면 함께 이동한다. 오른쪽의 **가장 이른 시작 박**을 변경해도 항목 간 간격과 구간 길이를 유지해 일괄 이동한다. 방과 문이 공유하는 시작 박은 한 번만 이동하며, 적의 등장 박도 적 구간과 함께 이동한다.

**Ctrl+D**는 선택 항목을 같은 박에 복제하고 복제본을 선택한다. 이후 드래그나 시작 박 입력으로 위치를 정한다. 방·문은 같은 방 데이터에 속하므로 함께 복제된다. 선택한 적·카메라·흔들림의 소속 방도 함께 복제했다면 새 방에 연결된다. **Delete**는 선택 항목을 삭제하며 **Ctrl+Z**로 복제·이동·삭제를 되돌릴 수 있다.

문 판정선이 너무 일찍 시작한다는 이유로 저장을 막지 않는다. 반경이 0보다 작아지는 구간은 기존 표시 방식대로 중앙에 머물다가 확대한다. 정확 입력 시각과 허용 범위, 일정한 확대 속도의 계산은 유지한다.

숫자가 아니거나 음악 범위를 벗어난 시각, 정확 입력 이후의 등장/판정선 시작, 끊긴 방 연결, 중복 ID, 실제 플레이가 불가능한 판정 순서 등은 계속 검사한다.

## 타임라인과 화면 조작

타임라인은 **문 → 방 → 적 → 카메라 → 흔들림** 영역을 유지한다. **적 영역만** 방 진행 순서로 정렬하고, 같은 방의 적은 사격 정확 박 순서대로 연속된 행에 표시한다. 별도의 방 묶음 제목은 만들지 않는다. 판정선 시작과 정확 입력을 하나의 구간으로 연결하며 카메라/흔들림은 시작부터 종료까지 표시한다. 양 끝을 드래그하면 해당 시각, 가운데를 드래그하면 구간 전체를 옮긴다. 방 또는 문 구간의 시작을 옮기면 같은 방의 등장·이동 판정선·문 판정선 시작도 함께 바뀐다. 적 이외의 영역에서는 겹치지 않는 구간을 같은 행에 배치하고 겹치는 구간만 행을 나눈다.

- **전체 맵:** 모든 방문을 함께 보며 편집한다.
- **미리보기:** 선택한 음악이 현재 위치부터 재생되고 흰 기준선이 음악을 따라 움직인다. 재생 중에도 편집할 수 있다.
- **연출 재생:** 음악과 함께 시간을 진행한다. 편집은 잠기며 기준선 드래그 동안만 음악이 멈췄다가 놓은 위치부터 이어진다. 미리보기에서도 기준선 탐색은 동일하게 동작한다. 편집하려면 미리보기 또는 전체 맵으로 돌아간다.

맵과 타임라인 사이의 경계선을 위아래로 드래그해 두 영역의 높이를 조절한다. 타임라인 우클릭 드래그로 좌우를 탐색하며 `표시 박 수`로 한 화면의 범위를 설정한다. 맵에서는 휠로 확대하고 우클릭 드래그로 이동한다.

미리보기는 모든 입력을 정확하게 성공했다고 가정한 2D 표시이며 실제 씬 오브젝트를 움직이지 않는다. 카메라 사각형은 16:9 기준이다. 실제 음악/입력 확인은 Play에서 한다.

`씬에 적용`은 해당 씬의 다른 미저장 수정도 함께 저장한다. 적용 작업을 Undo로 취소했다면 씬과 에셋을 다시 저장해야 디스크에 반영된다. 기본 템플릿이 있는 MainScene에서 사용하며, 빈 씬 기본 구성 생성과 곡 중간 BPM 변경, 오디오 파형 표시는 포함하지 않는다.
방 이름의 `nth/nbeat`에서 nbeat는 정확 입력 박이다. 맵의 방 이름은 이동 정확 박이며 타임라인의 문·적 이름은 각각 해당 사격의 정확 박이다.

맵과 타임라인 사이 경계선을 조절하면 타임라인이 창의 남은 높이를 채운다. 하단에 불필요한 빈 공간을 따로 남기지 않는다. 방 추가 방향 버튼 아래에는 위치 이동과 방 삭제 버튼이 나란히 있다.

오디오 미리듣기는 씬 AudioSource를 생성하지 않고 Unity Editor의 클립 미리보기 채널을 사용한다. 음악의 실제 샘플 위치로 기준선과 연출을 평가한다. 창 닫기, 전체 맵으로 전환, 채보 변경, Unity Play 진입 시 미리듣기를 정지한다. 정지된 상태에서 다시 편집하며 듣고 싶으면 미리보기 버튼을 누른다.

개발 참고: Unity 공식 [AudioUtil 소스](https://github.com/Unity-Technologies/UnityCsReference/blob/master/Editor/Mono/Audio/Bindings/AudioUtil.bindings.cs)의 클립 재생 및 샘플 위치 API를 별도 어댑터로 감쌌다. 지원 API가 없는 Editor에서는 안내 메시지를 표시한다.
