# 시각적 맵 에디터 사용법

## 시작과 저장

편집할 스테이지 씬을 열고 Play를 종료한다. 마피아는 `MafiaStage01` 씬과 `Stage1_Full` 채보를 사용한다. `Window > Gun > 시각적 맵 에디터`에서 Room Chart를 지정하면 기존 작업을 자동으로 불러온다. 편집용 데이터가 없으면 현재 씬에서 자동으로 가져온다. 곡·기본 설정 탭에서 음악, BPM, 첫 박 시각, 분할과 판정 범위를 설정한다.

상단에는 `저장`과 `씬에 적용` 버튼이 있다. `저장`은 편집 중인 채보 에셋만 저장한다. 씬 연결이나 완성된 채보가 없어도 저장할 수 있다. `씬에 적용`은 현재 채보를 검증한 뒤 실제 씬에 방·문·적을 미리 배치하고 연결 및 씬·채보 파일 저장까지 처리한다. 실행 중 생성하지 않는다. 적용 중 연결 검사 실패 시 변경을 Undo로 되돌린다.

**음악 재생 전 대기 (박)**는 **음원 내 첫 박 시각 (박)** 바로 아래에 있다. 채보가 시작된 뒤 음악을 재생하기까지의 무음 구간이며, 0이면 음악을 즉시 재생한다. BPM 120에서 4박을 입력하면 채보가 2초 먼저 진행된 뒤 음악이 시작된다. 첫 박 시각이 0인 경우 대기 구간은 -4박부터 0박까지이며 여기에 방 등장이나 노트를 배치할 수 있다. 첫 박 시각은 음원 안의 0박 위치를 정하는 별도 설정이다. 두 설정 모두 BPM을 바꾸어도 입력한 박 수를 유지하며 미리보기와 씬 적용 후 게임 재생에 반영된다.

**음원 내 첫 박 시각 (박)**을 바꿀 때는 타임라인의 표시 구간을 유지한다. 값을 1박 늘리면 음원 파형과 음악 시작선이 채보에 대해 왼쪽으로 1박 이동한다. 따라서 음원 파일 자체의 앞부분 무음을 지나 실제 첫 타격을 0박에 맞출 수 있다. `음악 시작 · 대기 4박` 선 앞의 빈 구간은 음원 파일의 무음이 아니라 **음악 재생 전 대기**로 추가한 시간이다.

## 방을 기준으로 편집

맵의 방을 클릭하면 오른쪽에서 그 방의 모든 설정을 편집한다. 별도의 선택/배치 도구 탭은 없다. 같은 좌표에 여러 방문이 겹쳐 있으면 나열된 `nth/nbeat` 이름 중 원하는 것을 클릭한다. 빈 곳을 누르거나 겹친 칸을 반복 클릭해도 다른 방으로 자동 순환하지 않는다.

- **방·판정선 시작 박:** 방 등장, 이동 판정선 시작, 문 판정선 시작의 공통 시각. 여러 방에 같은 값을 넣으면 동시에 등장한다. 기존 채보는 방 등장 박을 기준으로 통일한다.
- **방 이동 정확 박:** WASD 입력 시각.
- **입구 문:** 문을 켜거나 끄고 사격 정확 박을 설정한다. 문 판정선은 방 등장과 동시에 시작한다.
- **옆에 방 추가:** ↑ → ↓ ← 중 원하는 방향 버튼을 누르고, 이동 박자를 직접 입력해 확정한다. 타임라인 커서 시각을 자동으로 사용하지 않는다.
- **기존 구간 사이에 복도 삽입:** 앞쪽 방을 선택하고 방향 버튼을 누른 뒤, 새 방의 가로·세로와 정확한 이동 박을 입력한다. `뒤쪽 방을 함께 밀어서 연결`을 켜면 사무실 등 다음 방부터 마지막 방까지 위치를 함께 옮겨 연결한다. 선택한 방과 다음 방의 이동 박 사이를 입력하며 기존 방 ID·박자·뒤쪽 방 사이 배치는 유지한다. 사무실 등장 박 자체를 늦추려면 사무실·창문·탈출 채보를 별도로 함께 옮긴다. 긴 복도 크기는 추가 창에서 먼저 지정하고, 배치 후 Ctrl+Z로 삽입과 뒤쪽 이동을 함께 취소할 수 있다.
- **방 위치 이동:** 방을 드래그하면 시간순 이전 방의 가장 가까운 면에 자동으로 붙는다. 긴 면에서는 기본 방 크기(기본값 6) 간격으로 위치를 선택한다. 예를 들어 6×18 방 옆에는 6×6 방을 위·가운데·아래 세 위치에 붙일 수 있고, 6×12 방의 반 칸 보정도 자동으로 계산한다. X/Y 보정값은 직접 입력하지 않는다. 시작 방은 이전 방이 없으므로 기본 격자로 이동한다. 클릭만 하면 위치는 바뀌지 않는다. 겹친 방은 이름을 잡아 끈다. Escape로 취소하고 Ctrl+Z로 되돌릴 수 있다. 기존 **방 위치 이동** 버튼도 같은 자동 맞춤을 사용한다.
- **여러 방 위치 이동:** 맵에서 Shift 클릭으로 방을 선택에 추가하거나 해제한다. 선택된 여러 방 중 하나를 드래그하면 방 사이 간격과 세부 위치를 유지하며 함께 이동한다. 선택 중 시간순 첫 방을 그 이전 방의 면에 맞추며, 시작 방이 선택에 포함되면 전체를 격자로 이동한다. 타임라인 다중 선택으로 강조된 방들도 맵에서 함께 이동할 수 있다. 겹친 방은 이름을 잡아 끈다. 노란 테두리로 이동 위치를 확인한 뒤 마우스를 놓으면 적용되며, Escape로 취소하거나 Ctrl+Z로 전체 이동을 한 번에 되돌린다.
- **이 방 삭제:** 해당 방과 소속 적·연출을 삭제한다. 시작 방은 삭제할 수 없다.
- **선택한 방 복제:** 위쪽 맵에서 방을 하나 또는 여러 개 선택한 뒤 **Ctrl+D**를 누르면 선택한 방·문·소속 적을 같은 위치·박에 함께 복제하고 복제본을 선택한다. 방 크기·위치 보정·이동 시간·속도 곡선과 적의 배치·등장/사격 박자도 유지된다. 복제된 적은 새 방에 연결되며 방과 함께 타이밍을 조절할 수 있다. 겹친 복제본은 이름을 잡아 끌어 위치를 바꾸고, 타임라인에서 사용할 박자를 조절한다. **Ctrl+Z**로 한 번에 복제를 되돌릴 수 있다. 카메라·흔들림도 복제하려면 타임라인에서 해당 항목을 함께 선택한다.

Bundle 기능은 제거했다. 기존 에셋을 열면 Bundle 등장 시각을 각 방의 등장 시각으로 옮겨 보존한다. 이후 한 방의 등장 박을 바꿔도 다른 방은 바뀌지 않는다.

진행 방향은 시간순 방의 위치로 자동 계산하고 화살표로 표시한다. 같은 좌표도 이전 방이 사라진 뒤 다시 방문할 수 있다. 늦은 성공 입력과 이동 애니메이션까지 고려해 같은 위치의 방들이 동시에 나타나지 않도록 설정한다.

직사각형 방에서 캐릭터의 도착 위치는 **다음 방과 맞닿은 칸의 중심**이다. 칸 크기는 기본 방 크기(기본값 6)를 사용한다. 다음 방이 오른쪽 끝 아래에 연결되어 있으면 현재 가로방의 오른쪽 끝 칸까지 이동한다. 해당 방의 **이동 시간 (박, 0: 기본값)**과 **이동 속도 곡선**으로 그 지점까지의 전체 이동을 조절한다. BPM 120에서 1박은 0.5초이며, 직접 입력한 이동 박 수는 맵 에디터에서 BPM을 바꿔도 유지된다. 0이면 기존 기본 이동 시간을 사용한다. 공유 통로를 거쳐 이동하며 미리보기와 실제 플레이에 같은 경로·곡선이 적용된다. 마지막 방은 방 중심에 도착한다.

## 적과 카메라

선택한 방의 **이 방의 적**에서 **좌표로 적 추가** 또는 8방향 버튼으로 적을 추가한다. 이미 배치한 적은 맵의 작은 원, 오른쪽 적 목록 또는 타임라인에서 선택한다. 같은 위치에 여러 적이 겹치면 목록이나 타임라인에서 원하는 사격 박의 적을 먼저 선택한다.

적을 선택했을 때만 아래 위치 설정이 나온다. 방 이동은 기존 격자 방식 그대로다.

1. **숫자로 배치:** **좌표 직접 지정**을 켜고 **방 중심 기준 X / Y**를 입력한 뒤 Enter를 누른다. `(0, 0)`은 방 중심이고 X는 오른쪽이 +, Y는 위쪽이 +다. 예를 들어 `X=-1.5, Y=0.8`이면 중심에서 왼쪽 1.5, 위 0.8이다. 처음 켤 때 기존 적 위치를 그대로 가져온다.
2. **마우스로 배치:** 맵의 적 원을 왼쪽 버튼으로 누른 채 원하는 곳으로 끌어 놓는다. 8방향 적도 자동으로 좌표 배치로 전환되므로 체크박스를 먼저 켤 필요가 없다. 격자·8방향·고정 반경에 맞추지 않는다. 단순 클릭은 위치를 바꾸지 않는다.
3. **취소·되돌리기:** 드래그 도중 `Esc`는 취소, 놓은 뒤 `Ctrl+Z`는 이전 위치로 되돌리기다. 좌표 직접 지정을 끄면 기존 방향 배치로 돌아간다.
4. **저장·적용:** `저장`은 편집 데이터만 저장한다. 실제 플레이에 반영하려면 `씬에 적용`을 누른다. 좌표는 일반 적의 외형·판정선·조준 위치에 함께 적용된다. 별도 보스 연출에 연결된 표적은 해당 연출의 위치·경로 설정을 따른다.

좌표는 방 중심에 대한 거리이므로 방을 옮기면 적도 함께 이동한다. 적의 위치를 드래그해도 사격 박자나 소속 방은 바뀌지 않는다. 다른 방으로 이동할 시점에 사격하도록 박자를 옮기면 새 소속 방의 중심을 기준으로 같은 X/Y를 사용한다. 자유 좌표는 벽 안으로 강제 보정하지 않으므로 화면에서 겹침을 확인한다. `미리보기`에서도 보이는 적을 배치할 수 있으며 적을 누르면 음악이 멈춘다. `연출 재생` 모드는 편집할 수 없다.

아래에서 **적·판정선 시작 박**, **사격 정확 박**을 설정하고 삭제할 수 있다. 적 등장과 판정선 시작은 항상 같다. 적의 소속 방은 **사격 정확 박**으로 자동 결정한다. 방 A의 이동 정확 박 이상, 다음 방 B의 이동 정확 박 미만에 사격하면 A에 속한다. 사격 정확 박이 B의 이동 정확 박과 같으면 B에 속한다. 첫 이동 전의 사격은 시작 방에 속한다. 적·판정선 시작이 방 이동보다 빨라도 사격 시점의 방 소속을 유지한다. 방이나 적의 박자를 수정·드래그·복제하면 소속이 다시 계산되며, 저장과 씬 적용에도 같은 규칙을 사용한다.

**이 방의 카메라**에서 카메라 이동 또는 흔들림을 추가한다. 이동은 시작·지속 박, 도착 위치·크기·보간을 설정한다. 보라색 마커를 드래그해 도착 위치를 바꿀 수도 있다. 흔들림은 시작·지속 박, 강도와 빈도를 설정한다. 예전에 만든 소속 방 정보 없는 연출은 목록에서 계속 접근할 수 있다.

## 검증과 판정선

입장 후 적을 읽는 최소 대기 시간은 검사하지 않는다. 입장 전부터 보이는 적은 도착 후 바로 사격할 수 있다. 문·이동·적의 허용 판정 구간이 겹쳐도 정확 박의 진행 순서가 맞으면 허용한다. 이동은 이전 애니메이션 이후에 성공할 수 있는 입력 시간이 전혀 없는 경우에만 막는다. 같은 방의 같은 방향에 여러 적 채보를 만들 수 있다. 음원 종료 직전의 판정은 허용하며, 느림 허용 구간과 마지막 이동 애니메이션은 음원 종료 뒤에 끝나도 된다. 대기 시간과 곡 반복 옵션은 게임과 씬 적용의 음원 길이 검사에 동일하게 반영된다.

타임라인에서 **Shift 클릭**으로 항목을 선택에 추가하거나 해제한다. 여러 항목을 선택한 상태에서 선택된 구간을 드래그하면 함께 이동한다. 오른쪽의 **가장 이른 시작 박**을 변경해도 항목 간 간격과 구간 길이를 유지해 일괄 이동한다. 방과 문이 공유하는 시작 박은 한 번만 이동하며, 적의 등장 박도 적 구간과 함께 이동한다.

타임라인 상단의 **음원 파형**은 실제 음원 샘플을 약 5ms 간격으로 분석한다. 밝은 막대는 평균 에너지(RMS), 옅은 막대는 순간 최대 진폭을 표시한다. 최대치가 비슷한 음악에서도 지속음과 순간 타격의 차이를 볼 수 있고, **파형 대비**를 높이면 강약 차이가 더 강조된다. 밝은 막대는 곡 전체의 최대 RMS를 기준으로 표시하므로 좌우 이동·확대 때 기준이 바뀌지 않는다. 음정의 높낮이를 나타내는 표시는 아니다. 박자 눈금·확대/축소·좌우 탐색과 함께 움직이며, 첫 박 시각과 음악 재생 전 대기를 반영한다. 반복 재생 설정에서는 파형도 반복된다. 미리보기 중에는 파형 위의 흰 선으로 현재 위치를 확인하고 파형을 클릭·드래그해 재생 위치를 옮길 수 있다. 최초 분석에는 잠시 시간이 걸리며 결과는 캐시한다. 압축 음원은 로컬 파일을 분석용으로 디코딩하고 음원 가져오기 설정은 변경하지 않는다.

맵과 타임라인 사이를 오가며 이미 선택된 항목을 클릭해도 다중 선택은 유지된다. 맵에서 여러 방을 선택한 뒤 타임라인에서 강조된 항목을 누르면 강조된 방·문·적·연출 구간을 함께 선택해 타이밍을 조절한다. 타임라인에서 여러 항목을 선택한 뒤 맵의 해당 방을 눌러도 기존 선택을 유지한다. 선택되지 않은 항목을 일반 클릭하면 그 항목으로 선택을 바꾸고, Shift 클릭은 추가·해제로 동작한다.

**Ctrl+D**는 선택 항목을 같은 박에 복제하고 복제본을 선택한다. 이후 드래그나 시작 박 입력으로 위치를 정한다. 방·문은 같은 방 데이터에 속하므로 함께 복제된다. 선택한 적·카메라·흔들림의 소속 방도 함께 복제했다면 새 방에 연결된다. **Delete**는 선택 항목을 삭제하며 **Ctrl+Z**로 복제·이동·삭제를 되돌릴 수 있다.

문 판정선이 너무 일찍 시작한다는 이유로 저장을 막지 않는다. 반경이 0보다 작아지는 구간은 기존 표시 방식대로 중앙에 머물다가 확대한다. 정확 입력 시각과 허용 범위, 일정한 확대 속도의 계산은 유지한다.

숫자가 아니거나 음악 범위를 벗어난 시각, 정확 입력 이후의 등장/판정선 시작, 끊긴 방 연결, 중복 ID, 실제 플레이가 불가능한 판정 순서 등은 계속 검사한다.

## 타임라인과 화면 조작

타임라인은 **문 → 방 → 적 → 카메라 → 흔들림** 영역을 유지한다. **적 영역만** 방 진행 순서로 정렬하고, 같은 방의 적은 사격 정확 박 순서대로 연속된 행에 표시한다. 별도의 방 묶음 제목은 만들지 않는다. 판정선 시작과 정확 입력을 하나의 구간으로 연결하며 카메라/흔들림은 시작부터 종료까지 표시한다. 양 끝을 드래그하면 해당 시각, 가운데를 드래그하면 구간 전체를 옮긴다. 방 또는 문 구간의 시작을 옮기면 같은 방의 등장·이동 판정선·문 판정선 시작도 함께 바뀐다. 적 이외의 영역에서는 겹치지 않는 구간을 같은 행에 배치하고 겹치는 구간만 행을 나눈다.

- **전체 맵:** 모든 방문을 함께 보며 편집한다.
- **미리보기:** 선택한 음악이 현재 위치부터 재생되고 흰 기준선이 음악을 따라 움직인다. 재생 중에도 편집할 수 있다.
- **연출 재생:** 음악과 함께 시간을 진행한다. 편집은 잠기며 기준선 드래그 동안만 음악이 멈췄다가 놓은 위치부터 이어진다. 미리보기에서도 기준선 탐색은 동일하게 동작한다. 편집하려면 미리보기 또는 전체 맵으로 돌아간다.

맵과 타임라인 사이의 경계선을 위아래로 드래그해 두 영역의 높이를 조절한다. 타임라인 우클릭 드래그로 좌우를 탐색하며 `표시 박 수`로 한 화면의 범위를 설정한다. 맵에서는 휠로 확대하고 우클릭 드래그로 이동한다.

미리보기는 모든 입력을 정확하게 성공했다고 가정한 2D 표시이며 실제 씬 오브젝트를 움직이지 않는다. 카메라 사각형은 16:9 기준이다. 실제 음악/입력 확인은 Play에서 한다.

`씬에 적용`은 해당 씬의 다른 미저장 수정도 함께 저장한다. 적용 작업을 Undo로 취소했다면 씬과 에셋을 다시 저장해야 디스크에 반영된다. 방·문·적 기본 연결이 있는 스테이지 씬에서 사용하며, 빈 씬 기본 구성 생성과 곡 중간 BPM 변경, 오디오 파형 표시는 포함하지 않는다.

자유 좌표의 모델 변환·복제·박자 이동·기존 배치·판정/재시작 검사와 런타임·Editor 컴파일을 확인했다. Unity에서 좌표 입력→드래그→Esc/Ctrl+Z→저장·재열기→씬 적용→플레이 확인은 사용자 담당이다.
방 이름의 `nth/nbeat`에서 nbeat는 정확 입력 박이다. 맵의 방 이름은 이동 정확 박이며 타임라인의 문·적 이름은 각각 해당 사격의 정확 박이다.

맵과 타임라인 사이 경계선을 조절하면 타임라인이 창의 남은 높이를 채운다. 하단에 불필요한 빈 공간을 따로 남기지 않는다. 방 추가 방향 버튼 아래에는 위치 이동과 방 삭제 버튼이 나란히 있다.

오디오 미리듣기는 씬 AudioSource를 생성하지 않고 Unity Editor의 클립 미리보기 채널을 사용한다. 음악의 실제 샘플 위치로 기준선과 연출을 평가한다. 창 닫기, 전체 맵으로 전환, 채보 변경, Unity Play 진입 시 미리듣기를 정지한다. 정지된 상태에서 다시 편집하며 듣고 싶으면 미리보기 버튼을 누른다.

개발 참고: Unity 공식 [AudioUtil 소스](https://github.com/Unity-Technologies/UnityCsReference/blob/master/Editor/Mono/Audio/Bindings/AudioUtil.bindings.cs)의 클립 재생 및 샘플 위치 API를 별도 어댑터로 감쌌다. 지원 API가 없는 Editor에서는 안내 메시지를 표시한다.
