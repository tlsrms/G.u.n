# 탑다운 2D 리듬 슈팅 게임 기획

## 1. 개요

- 엔진: Unity 6 / 2D / PC.
- 방 이동, 문 파괴, 적 처치가 각각 음악에 맞춘 채보 역할을 한다.
- WASD는 정해진 다음 방으로 이동하는 리듬 입력이다.
- 마우스로 조준하고 좌/우 클릭으로 사격한다. 두 버튼의 기능은 같다.
- 점수는 없고 입력의 정확도를 표시한다.
- 카메라는 플레이어를 따라가며, 플레이어가 화면 중앙에 위치하는 탑뷰로 표현한다.

## 2. 방과 진행 순서

### 방 구조

- 맵은 정사각형 방들로 구성된다.
- 각 방의 네 모서리에는 ㄱ자 벽이 있고, 상하좌우 각 변의 중앙은 통로로 열려 있다.
- 벽은 흰색이며, 색이 있는 사각 판정선이 정확한 시각에 흰 벽 위로 겹친다. 다음 차례가 아닌 미래 방은 회색으로 구분한다.
- 다음 방은 채보에 지정된 현재 방의 상하좌우 중 한 곳에 배치된다.
- 인접 방의 경계 벽 중심은 같은 위치에 배치하여 연결 부분도 한 줄 두께로 보인다. 중앙 통로의 너비는 모든 방과 문이 공유한다.
- 이동 순서는 하나로 고정된다. 여러 방이 보여도 순서를 건너뛰거나 임의의 방을 선택하지 않는다.
- 바로 다음에 이동할 방은 활성 색상으로, 그 이후의 미래 방들은 회색으로 구분한다.

### 방 표시

- 각 방의 등장 시각은 채보에 설정한다. 화면에 동시에 보이는 미래 방의 수는 고정하지 않는다.
- 빠른 곡이나 밀집된 채보에서는 여러 미래 방과 각각의 판정선이 동시에 보일 수 있다.
- 방은 이동 판정 시각에서 설정한 방 선행 시간을 뺀 시각에 등장한다(곡 시작 이전이면 0초). 문도 이때 함께 등장하며, 선행 시간은 문 판정도 수행할 수 있게 충분히 길어야 한다.
- 방이 등장할 때 방과 그보다 큰 정사각형 판정선이 함께 흐릿하게 표시된다.
- 판정선은 점점 작아지며, 해당 방의 정확한 이동 입력 시각에 방과 완전히 겹친다.
- 방과 판정선은 정확한 시각에 가까워질수록 선명해진다.
- 정확한 시각 이후에도 판정선은 안쪽으로 계속 줄어들며 선명도는 유지한다. 흰 벽과 겹치는 동안은 허용 판정이고, 안쪽에서 겹침이 사라지는 순간 미처리 노트는 즉시 실패한다.
- 미래 방의 회색 구분과 각 방의 판정 시각에 따른 크기/선명도 변화는 함께 적용한다.

### 채보 순서

- 기본 순서: 현재 방의 적 전부 처치 → 다음 방의 문 파괴 → 다음 방으로 이동.
- 적이 없는 방에서는 적 단계를, 다음 방에 문이 없으면 문 단계를 생략한다.
- 현재 방의 적을 모두 처리한 다음에 문과 이동을 수행할 수 있도록 채보를 구성한다.
- 방/문이 미리 보이는 시점과 실제 입력 순서는 구분한다. 다음 방의 문이 보이더라도 그 판정 시각은 현재 방의 적 처치 이후다.

## 3. 방 이동

- 플레이어는 현재 방 중앙에서 대기한다.
- W: 위, A: 왼쪽, S: 아래, D: 오른쪽 방으로 이동한다.
- 입력은 채보 순서상 바로 다음 방을 기준으로 방향과 시각을 판정한다.
- 성공하면 짧은 이동 애니메이션으로 다음 방 중앙에 도착한다.
- 이동 애니메이션이 끝나면 이전 방을 제거하고 새 방의 적을 표시한다.
- 이동 애니메이션 중의 WASD는 무시하며, 이후 입력으로 예약하지 않는다.
- 그 외 플레이 진행 중에는 WASD를 너무 이르다는 이유로 무시하지 않는다. 성공 허용 구간보다 이른 입력은 모두 너무 빠름으로 즉사한다.
- 잘못된 방향 입력은 즉사한다. 이동 애니메이션 중 입력 무시가 우선한다.
- 키를 누르는 순간 한 번만 판정한다. 누르고 있어도 반복 이동하지 않는다.

## 4. 시간 판정

- 모든 채보의 정확한 판정 시각은 음악 시간에 고정한다.
- 이동을 빠름/느림으로 성공해도 이후 적, 문, 방의 판정 시각은 밀리지 않는다.
- 판정 명칭은 시간 순서로 너무 빠름 / 빠름 / 정확 / 느림 / 너무 느림이다.
- 빠름, 정확, 느림은 성공 허용 구간이다. 정확을 중심으로 앞에는 빠름, 뒤에는 느림을 둔다.
- 너무 빠름과 너무 느림은 성공 허용 구간 바깥을 뜻한다. 이동에는 너무 빠름보다 앞선 별도의 입력 무시 구간을 두지 않는다.
- 이동, 문, 적 모두 성공 시 영어 판정 텍스트를 표시한다: EARLY(파랑), ACCURATE(초록), LATE(주황).
- 시간 판정으로 사망하면 TOO EARLY(보라), TOO LATE(빨강)를 표시한다. 문·적 누락 원인은 별도 안내에 표시한다.

| 상황 | 방 이동 WASD | 문·적 사격 |
| --- | --- | --- |
| 성공 허용 구간보다 이른 입력 | 너무 빠름으로 즉사 | 대상 처리 없이 무효, 페널티 없음 |
| 성공 허용 구간 안의 입력 | 올바른 방향이면 이동 성공 | 조준 대상으로 선택된 문·적 처리 성공 |
| 미처리 상태로 느림 허용 구간 종료 | 너무 느림 진입 즉시 사망 | 너무 느림 진입 즉시 사망 |
| 입력 누락 | 느림 허용 구간 종료 즉시 사망 | 느림 허용 구간 종료 즉시 사망 |

- 문·적의 실패는 클릭할 때까지 기다리지 않고 시간 경과로 판정한다. 조준 방향과 관계없이 놓치면 사망한다.
- 방의 흰 벽, 방 판정선, 적의 흰 아웃라인과 판정 링은 같은 굵기를 사용한다. 판정선이 줄어드는 동안에도 선 자체의 굵기는 유지한다.
- 흰 선과 색 선의 중심이 일치하는 시각이 정확한 기준 시각이다. 바깥쪽 첫 접촉부터 안쪽 겹침이 끝나기 직전까지 빠름/정확/느림의 허용 구간이다.
- 판정선은 등장부터 실패 경계까지 일정한 속도로 줄어든다. 정확 시각 전후 허용 시간은 대칭으로 맞춘다.
- 축소 속도 = 공통 선 두께 ÷ 한쪽 허용 시간이다. 처음 등장할 때의 크기는 정확 시각까지 남은 시간으로 자동 계산한다. 일찍 등장하는 판정선일수록 더 크게 출발한다.
- 난이도는 허용 시간으로 조절하며, 선 두께를 바꿔도 해당 허용 시간에 맞춰 속도가 자동 조정된다. 예고 구간이나 정확 시각에서 속도를 바꾸지 않는다.

## 5. 문

- 다음 방에는 현재 방과 연결되는 입구에 문이 있을 수도, 없을 수도 있다.
- 문이 있다면 해당 방과 동시에 흐릿하게 등장한다.
- 방·문·적의 판정선은 공통 등장 불투명도에서 시작해 각자의 정확한 판정 시각에 완전히 선명해진다.
- 문은 방이 나타나는 순간 닫히기 시작하고 짧은 등장 애니메이션으로 두 문짝이 맞물린다. 이 동작은 문 사격 판정 시각과 분리하며, 사격 허용 구간이 시작하기 전에 닫힌다.
- 문 사격 타이밍은 방 안쪽에서 바깥쪽으로 커지는 주황색 사각 판정선으로 표시한다. 문 판정 시각에 방의 흰 벽과 중심선이 일치한다.
- 주황색 선이 흰 벽과 겹치는 전후 구간은 유효 판정이며, 정확 시각 이후에도 바깥으로 커진다. 겹침이 끝날 때까지 문을 파괴하지 못하면 즉사한다. 문을 파괴하면 주황색 선도 사라진다. 방 이동용 민트색 축소 판정선은 별도로 유지한다.
- 문은 조준 후 성공 허용 구간 안에서 사격해야 파괴된다. 놓치면 즉사한다.
- 문이 있는 방의 이동 시각은 문 판정 시각 + a로 설정한다. a는 양수이며 채보에서 조정한다.
- 문 판정이 먼저이며, 문+이동 동시 채보는 기본 구성으로 사용하지 않는다.
- 문에 실패하면 즉시 사망하므로 이후 이동 판정으로 넘어가지 않는다.

## 6. 적

- 적은 원형 본체와 흰색 원형 아웃라인으로 표현한다. 판정선도 색이 있는 원형 링이며, 정확한 시각에 고정된 흰 아웃라인과 겹친다.

- 적은 해당 적의 판정 시각에서 설정한 선행 시간을 뺀 시각에 등장한다. 방 도착보다 이르면 도착 순간부터 표시한다. 등장 전에는 조준·사격 대상에 포함하지 않는다.
- 플레이어가 있는 방 중앙을 기준으로 상하좌우와 네 대각선, 총 8방향 중 채보에 지정한 위치에 배치한다.
- 플레이어 중심에서 적까지의 거리는 조준 호의 반지름과 같다.
- 각 적은 별도의 사격 채보이며 각각 음악에 고정된 판정 시각을 가진다.
- 적은 흐릿한 모습과 적보다 큰 흐릿한 판정선으로 등장한다.
- 정확한 시각에 가까워질수록 적과 판정선이 선명해지고 판정선이 줄어든다.
- 정확한 시각에 판정 링의 중심선이 흰 아웃라인의 중심선과 일치한다. 이후에도 안쪽으로 계속 줄어들며, 흰 아웃라인과 겹치는 동안 허용 판정이다. 겹침이 완전히 사라질 때까지 처치하지 못하면 즉시 사망한다.
- 성공 허용 구간 안에서 사격해 처치한다. 놓치면 즉사한다.
- 늦게 이동해도 적 판정 시각은 변하지 않으므로 적을 볼 수 있는 시간이 짧아질 수 있다.
- 가장 늦은 성공 입력 후 이동 애니메이션을 마쳐도 첫 적을 인지하고 사격할 시간이 남도록 채보를 구성한다.
- 현재 방의 모든 적을 처리한 뒤 다음 문과 방 이동을 수행하도록 구성한다.

## 7. 조준과 사격

### 조준 표시

- 마우스 방향으로 플레이어 중심의 부채꼴 조준 범위를 회전한다.
- 부채꼴 내부를 채우거나 반지름 방향의 선을 표시하지 않는다. 마우스 방향을 따라가는 푸른 호 선만 표시한다.
- 마우스 방향은 부채꼴의 중앙선 방향이다. 중앙선은 대상 선택 기준이며 별도로 그리는 선이 아니다.
- 조준 호는 방향을 알려주는 표시다. 사격 정확도는 클릭 시각과 대상의 판정 시각 차이로 결정한다.

### 대상 선택

- 조준 부채꼴 안의 표시된 미처리 문·적 중 중앙선과 각도 차이가 가장 작은 대상 하나를 선택한다.
- 대상을 먼저 선택한 뒤 그 대상의 입력 시각을 판정한다.
- 중앙선에 가장 가까운 대상이 아직 성공 허용 구간에 들어오지 않았으면 사격은 무효다. 옆에 있는 다른 판정 가능한 대상을 대신 처리하지 않는다.
- 현재 조준 대상으로 선택된 적에는 점을 표시한다. 조준 대상이 바뀌면 점도 해당 적으로 옮긴다.

### 사격 동작

- 좌/우 클릭 모두 같은 사격 기능이다. 버튼을 누를 때마다 한 번 사격한다.
- 클릭 순간 선택된 대상 하나를 즉시 판정한다. 문은 파괴하고 적은 처치한다.
- 총알은 발사/명중을 보여주는 시각 연출이다. 총알 비행 시간으로 실제 판정을 지연하지 않는다.
- 버튼을 누르고 있어도 연속 사격하지 않는다. 클릭 간 대기시간은 없다.
- 대상이 없는 클릭과 선택된 대상의 성공 허용 구간 밖 클릭에는 페널티가 없다.

## 8. 실패, 재시작, 클리어

- 잘못된 이동 방향, 너무 빠른 이동 입력, 이동 입력 누락, 문·적 처리 누락 시 즉사한다.
- 실패하면 이후 채보 처리를 중단한다.
- 체크포인트는 없다. 재시작하면 음악과 모든 방·문·적·판정을 처음 상태로 초기화한다.
- 채보의 마지막 방까지 진행하고 필요한 판정을 모두 성공하면 클리어한다.

## 9. 제작 및 조정 기준

- 전용 씬을 새로 만들어 이 기획을 기준으로 처음부터 제작한다.
- 방, 문, 적, 플레이어와 표시 오브젝트는 가능한 한 씬에 미리 배치한다. 등장/소멸은 미리 배치한 오브젝트의 표시 상태와 연출로 처리한다.
- 판정 폭, 방 등장 선행 시간, 이동 애니메이션 길이, 문과 이동 사이의 a, 조준 호 반지름/각도는 조정 가능한 값으로 둔다.
- 이동 애니메이션 때문에 다음 이동 입력이 무시되는 채보가 생기지 않도록 간격을 확보한다.
- 적 → 문 → 이동의 각 성공 허용 구간과 이동 완료 시점을 고려하여 수행 가능한 순서로 채보를 구성한다.
- 게임 화면에서 구현 상세나 디버그 정보를 필수 조작 안내와 섞지 않는다.

- Unity 실행 및 플레이 검증은 사용자가 담당한다.
