# 공용 탑뷰 다리

- `TopDownLegs.prefab`: SpriteRenderer를 쓰는 일반 적·보스용.
- `TopDownLegsUI.prefab`: Canvas 아래 UI 캐릭터용.

캐릭터 프리팹 편집 모드에서 이동하는 캐릭터 루트의 자식으로 배치합니다. 다리 프리팹 루트 위치·회전은 0으로 두고 외형에 맞게 전체 크기를 조절합니다. `Motion Source`에는 실제 이동하는 캐릭터 루트를 연결하세요. 기본값은 다리 프리팹 루트 자신입니다.

실제 위치 변화가 있을 때만 양쪽 Hip이 활성화되어 번갈아 움직입니다. 정지하면 즉시 숨겨집니다. 이동 방향을 상체의 로컬 좌표로 변환하므로 마우스 조준과 보행 방향이 달라도 사용할 수 있습니다. 한 프레임에 `Teleport Distance`보다 많이 이동하면 순간이동으로 보고 다리를 숨깁니다.

골반의 연결점은 몸통 아래에 유지하고, 양발이 이동 방향의 앞과 뒤를 서로 반대로 오갑니다. 다리가 몸 아래를 통과하는 순간에는 세로 투영 길이가 0이 되고, 반대편으로 내딛을 때 다시 드러납니다. 좌우로 휘젓는 회전은 없습니다. `Stride`는 앞뒤 보폭이며 기본값은 0.32입니다. `Cycles Per Second`는 기본 보행 속도입니다. `Units Per Rig Unit`은 월드 프리팹 1, UI 프리팹 60이며 관절 좌표의 단위에 맞춥니다. 월드 다리 Sorting Order는 10~12입니다. 캐릭터 몸통보다 낮게 설정하고, UI에서는 몸통보다 앞쪽 형제 순서에 두어 몸 아래로 그려지게 하세요.

허벅지·정강이·발 외형은 각 Hip → Knee → Ankle 관절 아래에서 교체할 수 있습니다. 직접 Animation 클립으로 제어하려면 `TopDownLegMotion`을 비활성화한 뒤 양쪽 Hip을 활성화하세요. 사망 등으로 캐릭터를 숨길 때는 루트를 끄거나 `SetVisible(false)`를 호출합니다.

플레이어는 기존 리그 안의 다리에 같은 컴포넌트를 연결했습니다. 공용 프리팹은 일반 적·보스에 추후 배치하기 위한 독립 에셋이며, 현재 적·보스에는 자동으로 추가하지 않습니다. 런타임 오브젝트 생성은 없습니다.
