# 고기방패 등장 연출 배치

`MafiaShieldAmbush.prefab`은 닫힌 문이 열리고, 부하를 앞세운 보스가 등장하여 3발을 쏜 뒤 물러나는 연출이다. 기존 방 이동 판정으로 피신하며 문·부하·탄환에는 별도 판정이 없다. 같은 방에 맵 에디터로 일반 적 채보를 넣어도 된다.

## 처음 배치하기

1. Unity 실행을 멈추고 `MafiaStage01`을 연다. 맵 에디터에서 사용할 이동 채보를 만든 뒤 **적용**한다. Inspector의 목록은 적용한 채보를 사용한다.
2. Project 창에서 `Assets → Prefabs → Characters → MafiaShieldAmbush`를 Hierarchy의 빈 공간에 드래그한다. 자동 생성된 방이나 기존 `Mafia presentation` 안에 넣지 않고 독립된 루트로 둔다.
3. 이 오브젝트를 선택하고 Scene 창에서 **F**, 이동 도구 **W**를 누른다. 오브젝트의 중심이 보스가 나올 문 중심이다. 원하는 방의 벽에 직접 맞춘다. 루트의 Rotation은 0, Scale은 1로 두고 방향은 아래 설정으로 바꾼다.
4. Inspector의 **피신할 이동 채보**에서 해당 방을 **떠나는** 채보를 고른다. 예를 들어 `5번째 방 → 6번째 방`을 선택하면 보스는 5번째 방에 등장한다. 방 번호와 박자를 맵 에디터와 대조한다.
5. **보스가 나오는 벽**에서 위·왼쪽·아래·오른쪽을 고른다. Scene의 선이 방 안쪽을 가리키도록 배치한다. 플레이어가 피신할 통로와는 다른 벽에 배치하는 것이 기본이다.
6. **이동 몇 박 전 등장**은 기본 4박이다. 닫힌 문은 출발 방에 도착한 뒤 표시되고, 지정 박자에 열리면서 보스가 들어온다. **문에서 들어오는 거리**로 진입 깊이를 조절한다.
7. 씬을 저장하고 실행한다. 첫 발은 이동의 정확 박자, 이후 두 발은 난사 모션의 반동 시각에 맞춰 나간다. 총구는 플레이어가 떠난 자리를 향하며 다음 방까지 쫓아 조준하지 않는다.

Game Session은 같은 씬에 하나 있으면 자동으로 찾는다. 여러 개라면 필드에 해당 세션을 직접 드래그한다. 연결한 방이 사라졌거나 모션을 재생할 시간이 부족하면 Inspector에 이유가 표시된다. 시작 전 채보 간격 또는 선행 박자를 수정한다.

## 다른 방에서 반복하기

Hierarchy에서 연출 루트를 선택하여 **Ctrl+D**로 복제한다. 복사본을 다른 방의 벽에 옮기고 **피신할 이동 채보**와 **보스가 나오는 벽**을 바꾼다. 복제 직후에는 원본의 연결이 그대로이므로 반드시 새 채보를 고른다.

채보의 박자를 바꾸면 시작·공격 시각은 그 채보를 따라간다. 씬 위치는 자동 이동하지 않는다. 맵에서 방을 옮기거나 중간에 새 방을 넣어 경로가 바뀌면 연출 위치와 출발 방 연결을 확인한다. 맵 에디터의 방 복사 기능과 별개다.

## 모션과 외형 수정

- **등장 / 조준 대기 / 3발 난사 / 퇴장**에 기존 방패 클립 4개가 연결되어 있다. 클립의 자세는 Unity 기본 Animation 창에서 편집한다. 자세 편집 안내는 `Docs/MAFIA_MOTION_PRACTICE.md`를 참고한다.
- **클립 내 발사 시각** X/Y/Z는 난사 클립 안의 3발 시각이다. 기본값은 0.12 / 0.28 / 0.44초이며 모션 반동을 옮겼다면 함께 수정한다. 첫 발이 이동의 정확 시점에 오도록 난사 클립 시작 시각을 자동 계산한다.
- `Presentation / Actors / Mafia boss`는 공용 `MafiaBoss`의 중첩 프리팹이다. 부하는 같은 Actors 아래의 연출용 스프라이트로, 적 사격 판정선이나 RoomEnemy가 없다.
- 문은 배치한 벽을 가리는 독립 소품이다. 기존 통로 문·문 사격 채보를 교체하지 않는다. 부하와 보스가 일반 적이나 플레이어를 가리지 않도록 위치와 진입 거리를 조절한다.
- 공통 수정은 Project 창의 프리팹을 열어 편집한다. 씬의 복사본만 수정하면 해당 배치에만 적용된다. 사무실과 공유하는 보스 본체나 클립을 수정하면 인트로에도 영향을 줄 수 있다.

사망 시 새 총성·탄환을 중단하고, 재시작할 때 자세·문·발사 상태를 복원한다. 연출은 판정·음악 시작·스테이지 완료 조건을 바꾸지 않는다. 마지막 채보로 클리어되거나 더 뒤의 방으로 이동하면 남은 연출은 숨긴다.

## 확인 범위

`Tests/RoomRhythm/Run-Checks.ps1`로 시간 연결·일반 적 판정·기존 재시작 회귀 검사 및 실행/Inspector 코드 컴파일을 수행한다. `MafiaAmbushAssetChecks.py`는 프리팹 참조를 검사한다. Unity 가져오기 및 실제 배치·동작·음향 확인은 별도다.
