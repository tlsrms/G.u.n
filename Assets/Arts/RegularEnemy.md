# 일반 총잡이

`RegularEnemy.png`는 리깅·Animator가 없는 단일 탑뷰 스프라이트입니다. `Assets/Prefabs/Characters/RegularEnemy.prefab`에 몸체·조준 스크립트·판정 원을 묶었습니다. MainScene 및 Stage01~05의 적/편집용 템플릿은 이 공용 프리팹의 인스턴스이며, 맵 편집기에서 새로 배치하는 적도 프리팹 연결을 유지합니다. 적이 없는 스테이지에는 템플릿만 적용했습니다.

몸체만 플레이어를 조준하도록 회전합니다. 흰 외곽선과 색상 판정 원은 회전하지 않으며 기존 채보·등장 시점을 유지합니다. Sprite pivot은 몸통 중심, 총구의 sprite-local 좌표는 (0.215, 0.65)입니다.

적 사격 채보 실패 시 실패한 적을 특정하여 약 0.06초에 총구 섬광/사격선, 0.14초에 플레이어 피격 효과, 0.24초에 플레이어 숨김이 이어집니다. 이동 중 적 사격을 놓친 경우에도 충돌 대신 해당 적의 사격 연출을 사용합니다. 적이 없는 문 실패 등의 기존 사망은 별도입니다.

도형 제작 원본: `Tools/Characters/BuildRegularEnemy.py`. 재실행하면 이미지와 import 설정을 갱신하며 씬 오브젝트를 런타임에 생성하지 않습니다.

등장 시각까지는 숨겨져 있다가 등장 시점부터 원래 밝기·불투명도 100%로 표시됩니다. 등장 페이드와 다음 방 적의 몸체 밝기 감소는 적용하지 않습니다. 판정 원의 색과 타이밍은 유지합니다.
