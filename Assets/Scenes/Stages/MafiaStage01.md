# Stage 1 — Mafia

## 현재 구현한 흐름

사용자가 새로 작성한 채보를 기준으로 **일반 구간 → 긴 복도 → 보스 사무실 → 위쪽 창문 파괴·탈출 → 일반 사격 재개**를 연결했다. 이전의 아래쪽 회피·84발 요격 초안은 현재 씬에서 사용하지 않는다. 한 씬, `Stage1_Full.asset` 하나, 음악 시계 하나를 유지한다. Unity 실행 검증은 사용자 담당이다.

사무실 도착부터 위쪽 방 도착까지 15박, 130 BPM 기준 약 6.92초다. 맵 박자는 0부터이며 곡 시작 대기 4박은 그대로 보존했다. 복도에 추가한 사격 박자는 제작 초안으로, 음악을 청음해 확정한 최종 채보는 아니다.

## Unity에서 확인하기

1. `MafiaStage01` 씬을 다시 열어 저장된 새 구성을 불러온다.
2. **Game Session → Room Session → Debug Mode**를 켜고 실행하면 자동 진행으로 전체 연출을 확인할 수 있다.
3. 복도를 통과한 뒤, 사무실의 두 인물·책상·연기, AK 3발, 느린 탄환과 위쪽 창문을 확인한다.
4. 수동 테스트는 Debug Mode를 끄고 한다. 창문은 **마우스로 조준·사격**, 다음 이동 노트는 **위쪽 이동**이다. 놓치면 기존 사망 판정이 발생한다.
5. 사무실 대기·창문 실패·탈출 이후 각각 재시작해 연기·탄환·창문·카메라·모션이 초기화되는지 확인한다.

## 직접 수정할 곳

- **채보:** `Window → Gun → 시각적 맵 에디터`에서 `Stage1_Full`을 연다. 복도 적은 자유 좌표·드래그로 옮긴다. 채보 저장과 씬 적용은 기존 버튼을 사용한다.
- **모션:** `Mafia presentation / Mafia boss` 선택 → `Window → Animation → Animation`. [클립 편집 안내](../../../Docs/MAFIA_MOTION_PRACTICE.md)를 참고한다.
- **사무실 소품:** `Mafia presentation / Mafia office set` 아래 `Desk`, `Chair`, `Breakable window`의 외형·크기·색을 수정한다. 위치는 실행 시 사무실과 탈출 통로를 기준으로 다시 맞춘다.
- **연출 강도·클립 연결:** Game Session의 `Mafia Stage Director`에서 `Letterbox Height`, `Office Camera Size`, `Bullet Camera Size`, `Camera Kick` 및 모션 4개를 조절한다. Camera Size는 작을수록 확대된다.
- **효과음:** `Mafia office set`의 `Rifle Sound`, `Glass Sound`를 바꾸면 된다. 현재 두 효과음은 짧은 합성 초안이다.

방의 안정적인 ID로 연결한다: 복도 `room_fe5599bc`, 사무실 `room_5b48893d`, 탈출 `mafia_office_escape`. 맵 적용으로 씬 방이 재생성되어도 실행 시작 때 이 ID로 다시 찾는다. 방을 삭제하고 새로 만들면 Director의 해당 ID도 갱신한다. 사무실 다음 방은 위쪽 문과 이동 채보가 있어야 한다.

사무실·탈출 박자를 옮기면 `MafiaIntroTiming`이 적용된 노트에서 시각을 다시 계산한다. 3발은 창문 판정 3박 전부터 0.16초 간격이며, `Mafia_05_FireBurst3`의 0.12/0.28/0.44초 반동과 연결된다. 모션의 발사 키 시각 자체를 바꾸는 경우 이 기준 시각도 함께 수정해야 한다. 범용 시각적 연출 편집기는 아직 없다.

## 구현 경계와 보존 규칙

- `RoomSession`·`RoomRun`이 기존 판정·점수·음악·플레이어 이동을 소유한다. 슬로 모션은 탄환의 표시 경로에만 적용한다. `Time.timeScale`, 음악 속도, 허용 판정 시간은 바꾸지 않는다.
- `MafiaStageDirector`는 기본 Animation 클립을 곡 시각으로 샘플링한다. Animator는 자동 재생하지 않는다. 오른팔을 따로 덮어쓰던 구 코드는 교체했다.
- `MafiaOfficeSet`은 저장된 책상·의자·창문과 재사용하는 연기·탄환·탄피·섬광을 제어한다. 장식 탄환은 충돌 판정이나 추가 피해를 만들지 않는다.
- `RoomEnemy.TargetAt(time)`은 출현 이동 중 표시·조준·사격 끝점을 같은 시각으로 계산한다. 최종 좌표와 채보 판정 시각은 유지한다.
- `RoomCamera`의 스테이지 구도는 일반 추적 위에 적용한다. 인트로 줌 때문에 플레이어를 다시 작게 만들지 않으며 사망 카메라를 우선한다. 위로 이동할 때 제어를 돌려준다.
- 창문 외형만 교체하고 `RoomDoor`의 조준점·판정 링·문 파괴/이동 이벤트를 사용한다. 실패·재시작 시 카메라, 연출 플래그, 창문과 보스 자세를 복원한다.
- 마피아 몸통은 가로 약 27%, 앞뒤 약 21% 줄이고 어깨·소매를 좁혔다. 15개 클립의 팔을 새 체형에 맞췄으며 기존 연습 클립은 보존했다.

현재 저장 구성은 방 59개, 이동 58회, 적 사격 23회, 문 사격 1회다. 이전 마피아 표적·탄환 경로·고정 Shots는 씬에서 제거했다. 다른 스테이지에서 사용할 수 있는 범용 StageActionTarget은 유지한다.

## 이후 보스전 구상 — 아직 미구현

부하 방패·반복 회피와 마지막 3×3 홀은 이후 채보와 함께 연결한다. 복도는 이번 변경에서 사무실 앞 구간으로 옮겨 확정했다. 보스 피격은 실제 보스 명중 노트/부위에만 반응하게 연결하며, 일반 적이나 문 성공으로 보스를 흔들지 않는다.

### 마지막 홀의 칸과 이동

칸 이름은 설명을 위한 공간 이름이다. 채보 노트 ID와 같다고 가정하지 않는다.

| 왼쪽 위 NW | 위 중앙 N | 오른쪽 위 NE |
| --- | --- | --- |
| **왼쪽 중앙 W · 시작** | **중앙 C · 보스** | **오른쪽 중앙 E** |
| **왼쪽 아래 SW** | **아래 중앙 S** | **오른쪽 아래 SE** |

사용자가 설명한 초반 순서를 다음처럼 보존한다. `→`는 이동이고, 문 사격은 표시된 구간에만 추가한다.

1. W에서 아래 문 사격 → SW → W → C → 보스 1발 → S.
2. S에서 왼쪽 문 사격 → SW → S → C → 보스 2발 → S.
3. S에서 오른쪽 문 사격 → SE → S → C → 보스 1발 → E.
4. 이후 반시계 방향으로 진행하는 패턴을 이어 간다. 생략된 이후의 문 방향·사격 수·종료 횟수는 아직 확정하지 않는다.

**보스는 중앙 C 안에 계속 머문다. 처음에는 중앙보다 살짝 오른쪽에 위치하고, 플레이어가 반시계 방향으로 자리를 바꾸면 그에 맞춰 조금씩 위치와 방향을 바꾸며 마주한다.** 플레이어도 C에 들어와 공격하므로 두 캐릭터를 같은 점에 겹쳐 놓지 않는다. 보스의 이동은 중앙 칸 안의 작은 위치 조정이며, 플레이어를 따라 다른 칸으로 이동하는 동작이 아니다. 실제 간격과 자세는 배치·미리보기에서 조절한다.

같은 C를 여러 번 방문하는 일과 한 번 방문해서 2발을 쏘는 일을 각각 구분해야 한다. 보스 2발은 독립된 사격 노트 두 개로 만들고, 한 번의 클릭으로 두 판정을 처리하지 않는다. 보스 외형은 첫 명중 뒤에도 유지한다. 반복 방문의 문 파괴·되돌아가기 상태도 방문별로 관리한다.
